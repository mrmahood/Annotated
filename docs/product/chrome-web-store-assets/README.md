# Chrome Web Store listing assets

Drop owner-captured Production screenshots and promo tiles here before
submit. Do **not** commit invented or placeholder binaries. Walkthrough:
`docs/product/chrome-web-store-submit.md`.

Capture from Production (`https://annotated.cbandcoop.com` and the
Production-pinned extension), not Staging. Square corners, no padding
(full bleed). PNG or JPEG.

## Screenshots (at least one; five preferred)

Chrome accepts **1280×800** (preferred) or **640×400**.

| Filename | Size | Suggested content |
| --- | --- | --- |
| `screenshot-01-create-text-1280x800.png` | 1280×800 | Side panel Create → Text, selected passage |
| `screenshot-02-create-media-1280x800.png` | 1280×800 | Create → Video or Audio, 1–90s range |
| `screenshot-03-feed-1280x800.png` | 1280×800 | Side panel Feed with nested source cards |
| `screenshot-04-public-detail-1280x800.png` | 1280×800 | Public web annotation (attribution + original link) |
| `screenshot-05-open-source-1280x800.png` | 1280×800 | Open source amber highlight on the connected tab |

If 1280×800 is unusable (dense side-panel text), use the same names
with `640x400` and those pixel dimensions.

## Promo tiles

and do not print a store URL.
